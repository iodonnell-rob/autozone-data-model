1 Packaging Hierarchy: Pallet → Case → SKU
▼

Every automotive part exists simultaneously at different physical levels. Collapsing these into a single flat product record is a primary cause of DC receiving errors, over-weight hub delivery vehicles, and inaccurate store planograms. Because automotive parts are heavily driven by density and hazard classifications, correct packaging MDM is business-critical.

Packaging Level Stack — Automotive Data Flow
📦 Tier 1: Pallet / Heavy Load
GTIN-14 (Pallet) Ti × Hi (layers × cases) Gross weight (lbs) Pallet type (Standard/Heavy) Hazmat class (DOT)
📚 Tier 2: Case / Hub Replenishment
GTIN-14 (Case) Inner pack qty Case gross weight Case dimensions (L×W×H) SDS/Hazmat flags
⚙️ Tier 3: Consumer Unit (SKU)
UPC ACES (Fitment) PIES (Product Info) Core Charge Amt Retail dimensions Warranty length
Tier Entity Key Attributes Primary Consumers
Tier 1 📦 Pallet GTIN-14, Ti × Hi (layers × cases), Gross weight, Hazmat class, Pallet type DC Receiving, TMS (Load optimization), WMS (Slotting)
Tier 2 📚 Case GTIN-14, Inner pack configuration, Case cube, SDS/Hazmat flags WMS (Pick-face slotting), Hub-to-Store routing, DSD Receiving
Tier 3 ⚙️ SKU UPC, ACES (Fitment), PIES (Product Info), Core Charge, Retail dimensions Z-Net (POS system), AutoZone Pro, eCommerce catalog
The "Weight-Out" Problem in Auto Parts: Unlike fluffy consumer packaged goods, auto parts (rotors, batteries, fluids) are extremely dense. If Pallet and Case weights are inaccurate in the MDM, a carrier truck will "weight-out" (hit DOT weight limits) long before it "cubes-out" (fills the physical space), leading to severe compliance violations or stranded freight on the DC dock.

2 Product → Item Inheritance & Fitment
▼

In automotive MDM, Product is the logical parent entity (e.g., Duralast Gold Ceramic Brake Pads). The Item (SKU) is the physical child entity representing a specific application (e.g., fits 2018 Honda Civic).

Level What It Defines What It Inherits to Child
Product
(Parent)		 Brand identity, formulation, and AutoCare category. Holds base warranty and marketing copy. Brand, Sub-brand, AutoCare Category, Base Warranty
Item / SKU
(Child)		 Specific fitment, dimensions, and core values. Inherits the brand but carries application data. ACES Fitment Data, UPC, Physical Dimensions, Core Charge
Case
(Packaging)		 Store replenishment logic. Inherits hazard flags but extends with logistics for Hubs. Hazmat/SDS flags (inherited), Inner Pack Qty, Case GTIN-14
Pallet
(Logistics)		 DC logistics. Inherits hazard class for load building and trailer optimization. Hazmat Class, Ti × Hi, Total Pallet Weight

3 Real-World Example: Master Data Records
▼

To understand why the hierarchy matters, let's look at the actual master data records passing through the supply chain. Notice how the SKU record is built for the store (POS, Fitment, Core Charges), while the Case and Pallet records are built entirely for the distribution center and freight carriers.

Tier 3: Item / SKU Record (The Sellable Unit)

Example: Duralast Platinum AGM Battery (H6-AGM). Consumed by Z-Net (POS), AutoZone Pro, and eCommerce. It contains the strict ACES (fitment) and PIES (product info) standards required for aftermarket parts.

{
  "entity_type": "ITEM",
  "sku_id": "H6-AGM",
  "gtin_12": "051111556789",
  "brand": "Duralast Platinum",
  "pies_attributes": {
    "part_terminology_id": 10167, /* AutoCare ID for Automotive Battery */
    "cca_rating": 760,
    "reserve_capacity": 120,
    "weight_lbs": 45.5
  },
  "aces_fitment": [
    { "year": 2018, "make": "Honda", "model": "Civic", "engine": "L4-2.0L" }
  ],
  "retail_attributes": {
    "core_charge_amt": 22.00,
    "core_item_id": "CORE-BATT-01",
    "warranty_months": 36,
    "prop_65_warning": "TRUE"
  }
}

Tier 2: Case Record (Hub Replenishment Unit)

Example: 6-Pack of STP Motor Oil. Used by the WMS for Hub-to-Store picking. It tracks inner-pack quantities and ensures Hazmat rules roll up from the individual quart bottles.

{
  "entity_type": "CASE",
  "case_gtin_14": "20071153123454",
  "contains_sku": "STP-10W30-QT",
  "logistics_attributes": {
    "inner_pack_qty": 6,
    "case_weight_lbs": 12.4,
    "case_dimensions_in": "9.5 x 8.0 x 9.0",
    "corrugated_type": "ECT-32"
  },
  "compliance_attributes": {
    "dot_hazmat_class": "Class 9 - Misc Hazardous",
    "sds_required": "TRUE",
    "spill_containment_req": "YES"
  }
}

Tier 1: Pallet Record (The Logistics Unit)

Example: Pallet of Duralast Batteries. This Tier 1 record is what the TMS (Transportation Management System) uses to prevent trucks from exceeding DOT weight limits, and WMS for heavy-rack slotting.

{
  "entity_type": "PALLET",
  "pallet_gtin_14": "30051111556780",
  "contains_sku": "H6-AGM",
  "logistics_attributes": {
    "ti_hi": "10x4", /* 10 per layer, 4 layers high */
    "total_units": 40,
    "gross_weight_lbs": 1870.0, /* (40 * 45.5) + 50lb heavy-duty pallet */
    "pallet_type": "WOOD_HEAVY_DUTY_CHEP",
    "max_stacking_tiers": 1 /* Do not double stack */
  },
  "compliance_attributes": {
    "dot_hazmat_class": "Class 8 - Corrosive",
    "un_number": "UN2794",
    "sds_document_id": "SDS-AGM-001"
  }
}

4 Regulatory & Compliance
▼

Automotive retail carries significantly higher regulatory risk than standard retail, meaning attributes must be rigorously managed at every packaging level:

  • SDS & Hazmat (DOT): Fluids, aerosols, and batteries require Safety Data Sheets. The DOT hazmat flag must roll up from the SKU to the Case and Pallet to ensure drivers have the correct placards on their trailers.
  • Core Management: Alternators, starters, and batteries have core values. The MDM must link the "Finished Good Item" to a corresponding "Core Item" so inventory tracks the dirty, used part returning backward through the supply chain.
  • Prop 65 & State Fees: California Proposition 65 warnings must render online and on shelf labels based on SKU attributes. State-specific battery recycling fees require geographic attribute mapping.

5 Business Value: Routing & Revenue
▼

  • Hub & Feeder Routing: AutoZone utilizes a "Hub and Spoke" model, delivering parts from Mega-Hubs to local stores multiple times a day. Accurate Case and SKU dimensional data ensures that delivery totes are packed efficiently and driver vehicles aren't illegally overloaded with dense parts.
  • Commercial (DIFM) Trust: Professional mechanics ordering through AutoZone Pro rely on 100% accurate ACES fitment data attached to the SKU. Accurate item data means the right part arrives the first time, drastically reducing expensive commercial returns and bay-tie-ups.
  • Store Receiving: When case quantities and barcodes match the physical truck delivery, store staff can scan-receive an entire pallet in minutes rather than manually counting individual inner packs in the backroom.
